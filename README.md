# Гульмэн 3D — браузерная версия

Экспериментальная реконструкция «Гульмэн 3D: В поисках утраченного искусства» на Three.js, пригодная для GitHub Pages. Весь сайт статический, серверная часть и установка npm-пакетов не нужны.

## Что перенесено

- Все 9 оригинальных локаций из официального архива.
- 7 персонажей, иерархия HSK и 13 оригинальных анимаций.
- Текстуры, музыка, эффекты и комиксы-брифинги.
- Расстановка 1184 объектов из `Levels.Script`: противники, артефакты, припасы, магазины, выходы.
- Передвижение, прыжки и столкновения; камера от первого и третьего лица.
- Бой, четыре вида оружия, подбор предметов, переходы и сохранение номера миссии.
- Оригинальные рисованные меню, HUD и прицел. Кнопки расположены на надписях из игры; все 25 кадров комиксов совмещены с исходными текстовыми слоями.
- Гульмэн и Гульмоника: смена модели, анимаций и голоса без перезапуска уровня.
- Музыка меню и игры, реплики и эффекты с раздельной громкостью. Первый клик включает звук; настройки сохраняются.

Логика движения, ИИ, оружия, магазина и камеры **восстановлена заново**, потому что исходный код Delphi не обнаружен. Это не эмуляция Windows-исполняемого файла и не полное воспроизведение поведения оригинала. Время анимаций, баланс боя и размеры подбираемых предметов адаптированы. При продолжении начинается сохранённый уровень с восстановленными припасами; точная позиция и состояние противников не сохраняются.

## Запуск

Из папки проекта:

```sh
python -m http.server 8097 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8097. Файлы нельзя открывать через `file://`: браузеру нужен HTTP для модулей и ресурсов. WebGL необходим. Браузер может разрешить звук и захват мыши только после нажатия «В игру»; предусмотрен обзор перетаскиванием и стрелками.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD | Движение |
| Мышь / стрелки | Обзор |
| Shift / Space | Бег / прыжок |
| ЛКМ | Стрельба |
| ПКМ / R | Прицеливание / перезарядка в Enhanced |
| Ctrl | Присесть; на бегу — подкат в Enhanced |
| E | Подбор, магазин, выход |
| 1–4 | Оружие |
| F1 / F2 | Гульмэн / Гульмоника |
| C / M / Esc | Камера / карта / пауза |

Все миссии доступны из меню выбора уровня. На сенсорном экране доступны кнопки движения, прыжка, подбора и стрельбы; обзор — движением пальца по сцене.

В «Настройки → Управление» также есть выбор героя, чувствительность и инверсия мыши. В «Настройки → Звуки» — громкость музыки, эффектов и проверка голоса.

## Режимы графики

«Настройки → Графика» позволяет переключать режим без перезапуска:

- **Оригинал** — исходные изображения и базовый рендер, включён по умолчанию.
- **Калькулятор** — пониженное разрешение рендера и минимальная фильтрация для слабых устройств.
- **Enhanced** — отдельный пакет геометрии и настоящих PBR-текстур. Песок, камень, дерево, бетон и кирпич используют сканы Poly Haven; влажный берег темнее и более гладкий. Пляж получает отдельную сетку с мелким рельефом. Исходные UV не растягивают новые материалы на всю карту.
- Вода получает отдельную сетку волн, многослойную рябь, отражения HDR-неба, цвет по глубине и пену у берега. Это растровый шейдер, без трассировки лучей и без отражения всех объектов сцены.
- Объёмные папоротники и трава заменяют исходные кусты; ветер шевелит листья, дальняя мелкая растительность отсекается. На пляже добавлены сканированные камни.
- Катер, шезлонги, зонты, столы, ящики и бочки заново построены с деталями геометрии. Четыре модели оружия, перчатки, магазины и затворы созданы отдельно для Enhanced.
- HDR-освещение, настоящие локальные тени, контактное затемнение, умеренное свечение и FXAA дополняют новые ресурсы.

В Enhanced доступны «Авто», «Высокое» и «Лёгкое». Авто следит за длительностью кадров и адаптирует разрешение и эффекты. Лёгкий вариант уменьшает сетку воды, дальность и плотность травы, карту теней и количество выборок материала, отключает свечение и контактное затемнение. Оригинал и «Калькулятор» сохраняют исходную сцену; дополнительный пакет загружается только для Enhanced и освобождается при уходе из него. Оригинальные файлы и коллизии не меняются.

В Enhanced включены магазины и поэтапная перезарядка, прицеливание, затухающая отдача, инерция оружия, приседание и подкат. Магазины, затворы и руки движутся отдельно; камера плавно опускается при приседании. Кнопка «От 1-го лица / От 3-го лица» и клавиша C доступны в обоих режимах. Процедурные движения дополняют исходные скелетные анимации, персонажи и некоторые сложные архитектурные атласы остаются оригинальными. Это ограничивает общий уровень детализации: версия не заявляется полноценным AAA-ремейком.

Новые сетевые ресурсы занимают около 16 МБ. Все они поставляются вместе с сайтом; обращений к внешним библиотекам во время игры нет. Источники, лицензии и контрольные суммы: [материалы](assets/enhanced/SOURCES.md), [модели и небо](assets/enhanced/MODEL-SOURCES.md). Powered by [Poly Haven](https://polyhaven.com/).

## GitHub Pages

Публиковать ветку `main`, папку `/ (root)` через Settings → Pages. `.nojekyll` уже включён. Все пути относительные: сайт работает по адресу `<account>.github.io/gulman-web/`. Внешних CDN и аналитики нет.

## Воспроизведение конвертации

Оригинальный архив: [официальная загрузка](https://www.gulman.ru/supergulman007.php), [страница автора](https://www.gulman.ru/gul1.html).

Извлечь RAR в отдельную папку. Для конвертации требуются Python 3 и Pillow. Параметры скриптов можно увидеть через `--help`:

```sh
python scripts/prepare_assets.py --help
python scripts/prepare_characters.py --help
python scripts/prepare_ui.py --help
python scripts/validate_assets.py
```

Схема данных и преобразование координат описаны в `scripts/ASSET_FORMAT.md`. Оригинальные EXE/DLL не исполняются и в сайт не входят. Единственная не найденная текстура `GRANATE-.JPG` отсутствует уже в исходном архиве; для неё используется материал без текстуры.

## Проверки

```sh
node --experimental-loader ./tests/vendor-loader.mjs --test tests/*.test.mjs
```

Тесты также проверяют расход патронов, перезарядку, гонки загрузки оружия, процедурные движения, ограничение эффектов, переключение графики и освобождение ресурсов. Проверки столкновений охватывают пол, тонкие стены, ступени, склоны и потолок, а также загрузку геометрии и движение от стартовых точек всех девяти карт. Визуальная проверка не равнозначна полному прохождению каждой миссии.
