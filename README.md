# Гульмэн 3D — браузерная версия

Экспериментальная реконструкция «Гульмэн 3D: В поисках утраченного искусства» на Three.js, пригодная для GitHub Pages. Весь сайт статический, серверная часть и установка npm-пакетов не нужны.

## Что перенесено

- Все 9 оригинальных локаций из официального архива.
- 7 персонажей, иерархия HSK и 13 оригинальных анимаций.
- Текстуры, музыка, эффекты и комиксы-брифинги.
- Расстановка 1184 объектов из `Levels.Script`: противники, артефакты, припасы, магазины, выходы.
- Передвижение, прыжки и столкновения; камера от первого и третьего лица.
- Бой, четыре вида оружия, подбор предметов, переходы и сохранение номера миссии. Синие/жёлтые снаряды используют исходные спрайты, летят с восстановленными скоростями и проверяют столкновения на всём пути; гранаты летят по дуге. Бросок включает замах, выпуск из руки и возврат; отдельного исходного throw-клипа в архиве нет, поэтому этот переход поставлен заново на существующем скелете.
- Оригинальные рисованные меню с фоном на всю ширину экрана и исходным указателем-рукой с огоньком, HUD и красный прицел из `x2.bmp`. Кнопки расположены на надписях из игры; все 25 кадров комиксов совмещены с исходными текстовыми слоями. В магазине покупки подписаны рядом с исходными рисунками товаров, баланс и здоровье помещены на нарисованный терминал.
- Гульмэн и Гульмоника: смена модели, анимаций и голоса без перезапуска уровня.
- Музыка меню и игры, реплики и эффекты с раздельной громкостью. Первый клик включает звук; настройки сохраняются.
- Загрузка ограничивает одновременные запросы и повторяет временные сетевые ошибки. Неудачный запрос не остаётся в кэше: уровень можно открыть повторно без перезапуска вкладки.

Движение в режиме «Оригинал» использует восстановленные из `Game.dll` правила GLScene DCE: инерцию, эллипсоид, слабое управление в воздухе и две фазы прыжка. Граната вылетает сразу и отскакивает с потерей скорости. Это браузерная реализация; детали и отличия описаны в [ORIGINAL-PHYSICS.md](ORIGINAL-PHYSICS.md). ИИ, магазин, камера и баланс адаптированы. При продолжении начинается сохранённый уровень с восстановленными припасами; точная позиция и состояние противников не сохраняются.

## Запуск

Из папки проекта:

```sh
python -m http.server 8097 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8097. Файлы нельзя открывать через `file://`: браузеру нужен HTTP для модулей и ресурсов. WebGL необходим. Браузер может разрешить звук и захват мыши только после нажатия «В игру»; предусмотрен обзор перетаскиванием и стрелками.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD | Движение |
| Мышь / стрелки | Обзор |
| Shift / Space | Бег / прыжок |
| ЛКМ | Стрельба |
| E | Подбор, магазин, выход |
| 1–4 | Оружие |
| 5 / 6 | Гульмэн / Гульмоника |
| C / M / Esc | Камера / карта / пауза |

Все миссии доступны из меню выбора уровня. В паузе есть «Застрял? К началу уровня»: возврат сохраняет собранные артефакты, здоровье, деньги и патроны. На телефоне левый стик задаёт направление и скорость. При отклонении почти до края герой бежит. Справа можно вести обзор пальцем одновременно с движением и стрельбой. Кнопки справа отвечают за прыжок, взаимодействие и выбор оружия; верхняя панель открывает карту и брифинг, переключает героя и камеру. Кнопка с рамкой разворачивает игру и брифинги на весь экран в браузерах с поддержкой Fullscreen API. Кнопка «+» увеличивает страницу брифинга; увеличенную иллюстрацию можно прокручивать пальцем.

В «Настройки → Управление» можно отключить «Физика оригинала», если нужен адаптированный прыжок на сложном переходе. Переключение сохраняет текущее положение и прогресс. При потере захвата игра продолжается, а первый клик по сцене повторяет попытку захвата. Если браузер отклоняет запрос, для обзора можно зажать ПКМ и двигать мышь или использовать стрелки. В HUD доступна кнопка «Захватить мышь», если браузер допускает повторный запрос.

Героев можно выбрать клавишами 5 / 6 или кнопками «Гульмэн» и «Гульмоника» вверху экрана. F1 и F2 остаются у браузера. В «Настройки → Управление» также есть выбор героя, чувствительность и инверсия мыши. В «Настройки → Звуки» — громкость музыки, эффектов и проверка голоса.

## Режимы графики

«Настройки → Графика» позволяет переключать режим без перезапуска:

- **Оригинал** — исходные изображения, модели и базовый рендер с динамическими тенями, включён по умолчанию. На первом пляже восстановлен светлый голубой вид воды по кадру оригинальной игры: исходное небо, широкие мягкие отражения и медленное движение поверхности. Это отдельная визуальная реконструкция, а не извлечённый шейдер движка. Геометрия, берег и столкновения не меняются.
- **Калькулятор** — пониженное разрешение рендера и минимальная фильтрация для слабых устройств.
Если в браузере был выбран Enhanced, игра переключится на «Оригинал». Экспериментальные ресурсы и их источники доступны в [истории репозитория](https://github.com/ALEXGREENCH/gulman-web/tree/597d86a/assets/enhanced).

## Выстрелы и лут

Деньги появляются на земле после каждого побеждённого противника. Шанс патронов — 20%, аптечки — 1/7; количество восстанавливается из обработчика оригинальной игры. Выпавшие предметы используют оригинальные модели и подбираются клавишей E. Смещение проверяется по земле и стенам, чтобы предмет не оказался за препятствием.

Скорости, число снарядов, спрайты и вероятности восстановлены статическим анализом исходного Game.dll, без его запуска. В веб-порте по-прежнему общий запас боеприпасов, 100 HP и адаптированный урон/перезарядка; это не побитовое воспроизведение оригинального боя. Доказательства и ограничения — в [ORIGINAL-COMBAT.md](ORIGINAL-COMBAT.md).

## GitHub Pages

Публиковать ветку `main`, папку `/ (root)` через Settings → Pages. `.nojekyll` уже включён. Все пути относительные: сайт работает по адресу `<account>.github.io/gulman-web/`. Внешних CDN и аналитики нет.

## Воспроизведение конвертации

Оригинальный архив: [официальная загрузка](https://www.gulman.ru/supergulman007.php), [страница автора](https://www.gulman.ru/gul1.html).

Извлечь RAR в отдельную папку. Для конвертации требуются Python 3 и Pillow. Параметры скриптов можно увидеть через `--help`:

```sh
python scripts/prepare_assets.py --help
python scripts/prepare_characters.py --help
python scripts/prepare_ui.py --help
python scripts/validate_assets.py
```

Схема данных и преобразование координат описаны в `scripts/ASSET_FORMAT.md`. Оригинальные EXE/DLL не исполняются и в сайт не входят. Единственная не найденная текстура `GRANATE-.JPG` отсутствует уже в исходном архиве; для неё используется материал без текстуры.

## Проверки

```sh
node --experimental-loader ./tests/vendor-loader.mjs --test --test-concurrency=1 tests/*.test.mjs
```

Тесты проверяют расход патронов, перезарядку, гонки загрузки оружия и персонажей, движения, ограничение эффектов, переключение графики и освобождение ресурсов. Проверки столкновений охватывают пол, тонкие стены, ступени, склоны и потолок.

Контрольные маршруты кампании используют исходную геометрию, тот же порядок объединения материалов и тот же `WorldCollision`, что в игре: от исходного старта через все обязательные предметы до выхода. Положение непрерывно переносится между участками, без телепортации или отключения столкновений; подбор проверяет реальные расстояния и видимость. Критические прыжки и склоны карт 3, 4 и 6 дополнительно проверяются при шагах физики 25, 60 и 120 Гц. Параметры прыжка и допустимого уклона восстановлены отдельно для сложных карт; исходные файлы и размещение целей сохранены.

Это проверка геометрии и условий задания, а не прохождение кампании живым игроком: полный бой с врагами и все возможные действия игрока не моделируются. Возврат к началу уровня сохраняет найденные предметы в текущей игре; перезагрузка страницы начинает сохранённую миссию заново. Подробные результаты и ограничения — в [отчёте о прохождении](PROGRESSION.md).
